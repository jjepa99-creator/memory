## 🧪 핵심 사용자 여정(Core User Journey) 테스트 프로토콜: ZEPA Funnel Friction Point 분석

**목표:** ZEPA의 잠재 고객이 '인지(Awareness)'부터 '가치 인식(Perceived Value)'에 도달하기까지의 핵심 사용자 여정(Funnel)을 구조적으로 테스트하여, 전환율을 저해하는 마찰 지점(Friction Point)을 구체적으로 식별한다.

**가정된 환경:**
1.  **LP Copy:** (가정) "AI 기반 1인 기업 솔루션으로, 복잡한 과정을 단순화합니다."
2.  **Prototype:** (가정) 4단계 흐름 (랜딩 $\rightarrow$ 기능 소개 $\rightarrow$ 회원가입 $\rightarrow$ 첫 사용)

**테스트 방식:** Think-Aloud Protocol (사용자가 생각하는 대로 말하게 하기) 기반의 질적 사용자 테스트(Qualitative Usability Testing)를 주력으로 하며, 주요 지표는 A/B 테스트 가설로 전환한다.

---

### 🚀 [Phase 1] 진입 및 가치 제안 (Entry & Value Proposition)
**위치:** 랜딩 페이지 (LP)
**테스트 목표:** 방문자가 5초 이내에 ZEPA가 해결해 줄 수 있는 핵심 문제(Pain Point)를 명확히 인지하고, '나에게 필요한 서비스'라고 인식하게 하는가?

| 테스트 항목 | 측정 지표 (Metric) | 성공 기준 (Success Criteria) | 예상 마찰 지점 (Friction Point) |
| :--- | :--- | :--- | :--- |
| **A. 첫인상(Headline)** | 5초 이내 '문제점' 언급율 | 80% 이상의 사용자에게 핵심 Pain Point(예: "AI 활용 어려움")가 명확히 언급되어야 함. | **모호성:** 헤드라인이 너무 광범위하여, 어떤 종류의 '1인 기업'인지 특정하기 어려움. |
| **B. 가치 입증 (Social Proof)** | 신뢰도 인식 지수 (Trust Index) | 경쟁사 대비 ZEPA의 차별화된 성공 사례(Case Study)를 3가지 이상 인지해야 함. | **근거 부족:** "최고의 솔루션" 같은 주장이 근거 없는 수사적 표현으로 느껴지는 부분. |
| **C. CTA 명확성** | 다음 액션 선택률 (Next Action Selection) | 사용자가 '무료 맛보기' 또는 '데모 신청' 버튼을 고민 없이 클릭해야 함. | **방향성 혼란:** CTA 버튼이 너무 많거나, '무료'와 '유료' 옵션 간의 경계가 모호함. |

### 🧭 [Phase 2] 기능 탐색 및 깊이 이해 (Feature Discovery & Understanding)
**위치:** 기능 소개 섹션, 데모 페이지
**테스트 목표:** 사용자가 ZEPA의 핵심 기능(예: 템플릿, 자동화)을 학습하는 과정에서, 기능의 복잡성보다 '쉬운 사용법'에 집중하여 가치를 느끼는가?

| 테스트 항목 | 측정 지표 (Metric) | 성공 기준 (Success Criteria) | 예상 마찰 지점 (Friction Point) |
| :--- | :--- | :--- | :--- |
| **A. 핵심 기능 이해** | 기능 이해도 점수 (Feature Comprehension Score) | 3가지 핵심 기능(A, B, C)을 30초 이내에 구어체로 설명할 수 있어야 함. | **기술적 과부하:** 기능의 작동 원리(How it works) 설명이 너무 기술적이고 장황함. |
| **B. 사용자 플로우 예측** | 사용 가능성 (Perceived Usability) | 사용자가 스스로 "이걸 쓰면 내가 이렇게 할 수 있겠구나"라는 구체적인 시나리오를 1가지 이상 제시해야 함. | **갭(Gap):** 기능 소개가 '무엇을 할 수 있는지'만 나열하고, '어떻게 시작하는지'에 대한 가이드가 부재함. |
| **C. 단점 인지** | 한계 인식률 (Limitation Awareness) | ZEPA가 '모든 것'을 해결해 줄 것이라는 과장된 기대가 아닌, '특정 영역'에 강점이 있음을 인지해야 함. | **과대 포장:** 모든 것을 커버하는 것처럼 느껴져, 오히려 전문성이 떨어져 보임. |
