# 🎨 Designer — 개발자가 사용할 수 있는 간편하고 직관적인 UI/UX 디자인을 만들어내고, 이를 바탕으로 창의적이고 혁신적인 서비스 형태로 구체화시킵니다.

🎨 Designer: 작업 시작합니다.

CEO님의 지시는 핵심적인 다음 단계를 명확히 제시하고 있습니다. 이전 작업들이 '무엇을 할지(전략)'와 '어떻게 구현할지(백테스터)'를 정의했다면, 이제는 **'사용자가 이 시스템을 사용했을 때 어떤 경험을 하는지(UX)'**를 정의하여 제품의 실체를 완성해야 합니다.

따라서, 단순히 예쁜 UI를 만드는 것을 넘어, **백테스팅 과정에서 나오는 복잡하고 중요한 데이터를 사용자가 직관적으로 이해하고, 다음 전략 개선에 영감을 얻을 수 있는 인터랙티브 대시보드**를 설계하는 것이 가장 가치 있는 작업입니다.

---

### 🚀 🎨 디자인 작업 계획: Backtesting Results Visualization Dashboard

**목표:** 복잡한 백테스팅 결과(수익률, 최대 낙폭, 샤프 비율 등)를 한눈에 파악하고, 사용자가 즉시 다음 전략 수정에 활용할 수 있는 직관적이고 혁신적인 대시보드 와이어프레임을 설계합니다.

**전략:**
1.  **사용자 플로우 정의:** 사용자가 '전략 입력' $\rightarrow$ '백테스트 실행' $\rightarrow$ '결과 분석 및 개선'의 3단계 플로우를 거치도록 합니다.
2.  **핵심 컴포넌트 설계:** 백테스팅의 결과 지표를 시각화하는 대시보드 컴포넌트를 구체화합니다.
3.  **브랜드 시스템 적용:** ZEPA의 전문성과 신뢰성을 반영하는 색상 및 레이아웃 원칙을 적용합니다.

### 💻 산출물: Backtesting Dashboard (MVP 와이어프레임 및 디자인 브리프)

#### 1. 디자인 시스템 브리프 (Design System Brief)

*   **주요 컬러 (Primary Color):** `#007AFF` (신뢰감, 기술적 느낌)
*   **보조 컬러 (Secondary Color):** `#34C759` (성공, 수익 발생 시)
*   **경고 컬러 (Warning Color):** `#FF3B30` (손실, 위험 경고 시)
*   **배경/텍스트:** `#F9F9F9` (배경), `#1C1C1E` (텍스트, 다크 모드 대비)
*   **폰트 (Typography):** Pretendard 또는 Inter (직관적이고 가독성 높은 산세리프)

#### 2. 와이어프레임 레이아웃 (Dashboard Layout)

| 영역 | 컴포넌트 | 역할 및 기능 | 데이터 출처 |
| :--- | :--- | :--- | :--- |
| **A. 상단 네비게이션 (Header)** | 로고, 전략 선택 드롭다운, 실행 버튼 | 현재 분석 중인 전략 명시, 전략 간 빠른 전환. | N/A |
| **B. 핵심 성과 지표 (KPI Summary)** | 4개 카드 (총 수익률, 최대 낙폭, 샤프 비율, 승률) | 백테스트의 가장 중요한 수치를 시각적으로 요약. **(가장 눈에 띄게)** | Backtester Output |
| **C. 성능 추이 그래프 (Performance Chart)** | 라인 차트 (Equity Curve) | 시간 경과에 따른 자산 가치 변화를 보여줌. (가장 중요한 시각화) | Backtester Output |
| **D. 하위 분석 모듈 (Analysis Tabs)** | 탭 인터페이스 (수수료/세금, 포지션 히트맵, 거래 빈도) | 상세한 분석을 제공하여 사용자가 '왜' 이런 결과가 나왔는지 이해하게 함. | Backtester Output |
| **E. 전략 개선 제안 (AI Insight)** | 텍스트/토글 박스 | **(혁신 요소)** 분석 결과를 바탕으로 AI가 "다음 단계로 이것을 시도해 보세요"라고 제안. | Researcher/AI Logic |

#### 3. 🖼️ 시각화 예시 (Mockup Description)

**[와이어프레임 제목: ZEPA - Strategy Performance Dashboard]**

1.  **KPI Summary (B):** 4개의 큰 카드가 좌측에 배치됩니다.
    *   **Total Return:** `+45.2%` (녹색 강조)
    *   **Max Drawdown:** `-12.1%` (주황색 경고)
    *   **Sharpe Ratio:** `1.5` (신뢰감 있는 파란색)
    *   **Win Rate:** `68%` (명확한 텍스트)
2.  **Performance Chart (C):** 전체 영역의 60%를 차지하는 대형 라인 차트. X축은 시간(Date), Y축은 자산 가치(Equity Value)입니다. 그래프 아래에 '최대 낙폭 구간'을 자동으로 하이라이트 처리합니다.
3.  **AI Insight (E):** 대시보드 하단에 '🧠 ZEPA AI 인사이트' 섹션이 별도로 존재하며, "현재 전략은 변동성이 높습니다. [이동 평균 기간을 20일 $\rightarrow$ 50일로 확장]하여 안정성을 테스트해 보세요."와 같은 구체적이고 액션 가능한 텍스트를 제공합니다.
