CEO의 지시사항과 원 사용자 명령을 바탕으로, ZEPA 대시보드의 UI/UX 디자인 방향성을 '교육적 지식 통합' 관점에서 재정립하고, 전자책의 전문성을 반영한 최종 설계안을 완성하겠습니다.

기존 ZEPA 대시보드는 주로 '실시간 데이터 분석 및 트레이딩 실행'에 초점을 맞추었다면, 전자책 콘텐츠는 **'지식 습득 및 전략적 사고 과정'**을 보조하는 역할을 수행해야 합니다. 따라서 UI/UX의 최종 방향성은 **'지식 기반의 액션 플로우 (Knowledge-to-Action Flow)'**에 맞춰집니다.

### 📝 1. UI/UX 디자인 방향성 재정립: '지식 통합 모듈' 도입

전자책의 내용을 단순한 참고 자료로 보여주는 것을 넘어, 사용자가 지식을 습득하고 이를 실제 트레이딩 전략에 연결하는 **'지식 통합 모듈(Knowledge Integration Module)'**을 핵심 기능으로 설계합니다.

**[핵심 사용자 경험 (UX) 개선 목표]**
1.  **이해 (Understand):** 복잡한 개념을 단계별로, 전자책의 구조에 따라 명확하게 파악할 수 있도록 한다. (시각화)
2.  **연결 (Connect):** 파악된 지식(Concept)이 실제 시장 데이터(Chart)의 어떤 패턴과 연결되는지 시각적으로 매칭시킨다. (인사이트 추출)
3.  **행동 (Act):** 연결된 지식을 바탕으로 즉각적인 전략 수정 및 테스트를 할 수 있도록 액션 버튼을 제공한다. (전략화)

### 🎨 2. 브랜드 디자인 브리프 및 비주얼 시스템 업데이트

전자책의 전문적이고 학술적인 톤을 반영하여 기존 ZEPA 디자인 시스템을 확장하고, 새로운 '지식' 영역에 맞는 시각적 요소를 정의합니다.

#### 📑 ZEPA Design Brief: 지식 통합 모듈 (Knowledge Integration Module)
*   **목표:** 학습된 지식(Concept)을 데이터(Fact)와 연결하여 실행 가능한 전략(Action)으로 전환하는 사용자 경험 제공.
*   **톤앤매너:** 신뢰성, 학술적, 명료함 (Academic, Clear, Trustworthy).
*   **컬러 팔레트 수정 (Knowledge Accent):**
    *   **Primary (기존):** ZEPA Blue (전문성)
    *   **Secondary (기존):** Accent Green (긍정적 수익)
    *   **Tertiary (NEW - Knowledge):** **Slate Gray (#4A5568)** - 지식의 배경색/구분선.
    *   **Highlight (NEW - Insight):** **Deep Gold (#FFC72C)** - 중요한 통찰/핵심 개념을 강조할 때 사용. (금속성, 가치 강조)
*   **타이포그래피:**
    *   **Headings:** Pretendard Bold (강력한 구조 전달)
    *   **Body:** Pretendard Regular (가독성 최우선)
    *   **인용/정의 (Definition Box):** Monospace Font (기술적, 팩트 기반 느낌 부여)

#### 🖼️ 썸네일/컨셉 3안 (Knowledge Module 활용)
현재 대시보드와 전자책을 결합하는 과정을 시각화한 3가지 컨셉을 제안합니다.

| 컨셉 | 핵심 메시지 | 시각적 요소 (레이아웃) | 적합한 콘텐츠 |
| :--- | :--- | :--- | :--- |
| **A. The Blueprint (구조화)** | '개념 → 데이터 → 전략'의 3단계 플로우 강조. | 3단 분할 레이아웃. 좌(개념), 중(데이터 시각화), 우(액션 버튼). | 체계적인 이론 설명 및 자동화 로직 제시. |
| **B. The Deep Dive (심화 분석)** | 하나의 개념을 깊이 파고드는 'Zoom-in' 효과. | 중앙에 팝업 형태의 모듈 배치. 주변은 배경 데이터 흐름으로 처리. | 복잡한 시장 분석, 심층적인 이론 설명. |
| **C. The Timeline (변화 과정)** | 시간이 지남에 따라 지식이 축적되고 전략이 진화하는 과정. | 좌측에서 우측으로 흐르는 타임라인 형태의 섹션 분할. | 역사적 트렌드 분석, 매매 기법의 발전 과정. |

### 🛠️ 3. 최종 산출물: Knowledge Integration Module Blueprint

이 내용을 바탕으로, 개발자가 즉시 참고할 수 있는 **'지식 통합 모듈'의 Blueprint**를 완성하고, 필요한 디자인 시스템 파일을 업데이트하겠습니다.

<create_file path="designs/ZEPA_Knowledge_Module_Blueprint_V1.md"># 🧠 ZEPA Knowledge Integration Module Blueprint (V1.0)

## 🎯 목표
사용자가 전자책을 통해 얻은 전문 지식(Concept)을 실제 시장 데이터와 연결하여, 실행 가능한 트레이딩 전략(Action)으로 자동화하는 UI/UX를 구현한다.

## 📐 구조 및 레이아웃 (3-Column System)
**[전체 모듈 크기]:** 대시보드의 메인 패널 중 40% 영역 할당.
**[3단계 플로우]:**
1.  **CONCEPT PANEL (지식 습득):**
    *   **배경:** Slate Gray (#4A5568) 배경을 사용하여 '학습' 영역임을 명확히 구분.
    *   **요소:** 제목, 간결한 정의 박스 (Monospace Font 사용), 핵심 전제 조건 리스트.
    *   **인터랙션:** 'Concept Detail' 버튼을 눌러 해당 지식에 대한 상세한 전자책 발췌본(Source Reference)을 팝업으로 보여줌.
2.  **DATA MAPPING (데이터 연결):**
    *   **배경:** 흰색 배경.
    *   **요소:** 지식에서 정의된 '조건'에 부합하는 실제 시장 데이터 그래프가 하이라이트되어 표시됨. (예: 'RSI가 30 이하'라는 개념이 발생한 시점의 캔들만 Deep Gold로 강조).
    *   **로직:** Concept Panel에서 정의된 변수(Variable)와 차트 데이터가 실시간으로 매칭되어 시각적 증거를 제시.
3.  **ACTION & STRATEGY (실행 결정):**
    *   **배경:** 밝은 회색 배경.
    *   **요소:** 지식과 데이터가 일치했을 때, 시스템이 제안하는 '최적의 다음 행동' (매수/매도/대기)과 그 근거를 요약.
    *   **UX/UI:** 버튼 형태로 명확하게 제시하며, 클릭 시 백테스팅 결과와 함께 실행 옵션을 제공.

---
**[사용자 플로우 예시]**
1. 사용자가 '지지선 돌파'라는 지식(Concept)을 확인한다. (Knowledge Input)
2. 시스템은 과거 데이터에서 해당 지지선 돌파 시점의 차트(Data Visualization)를 보여준다.
3. 시스템은 과거 성공 패턴을 분석하여 '매수 후 일정 손절선 설정'이라는 액션(Action)을 제안한다.
4. 사용자가 이를 승인하고 실제 트레이딩에 적용한다.
