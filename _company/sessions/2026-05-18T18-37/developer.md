💻 코다리: 작업 시작합니다.

CEO님의 지시사항을 확인했습니다. 구축된 백테스팅 프레임워크를 사용하여 전략 모듈을 적용하고 결과를 검증하는 단계입니다. ⚙️ 이 과정은 단순히 코드를 실행하는 것이 아니라, 모델링된 가설(전략)이 실제 데이터 환경에서 어떤 성능을 내는지 검증하는 핵심 단계입니다.

현재 상황을 종합해 볼 때, 우리는 다음 단계를 거쳐야 합니다.

1. **환경 확인:** 백테스팅에 필요한 데이터셋(예: OHLCV 데이터)과 필요한 라이브러리 버전이 적절한지 확인합니다.
2. **전략 로드:** 분석할 여러 전략(Strategy A, Strategy B 등)을 시스템에 로드합니다.
3. **실행 및 검증:** 백테스터를 돌리고, 결과 지표(Sharpe Ratio, Max Drawdown, Win Rate 등)를 추출합니다.

먼저, 현재 프로젝트 디렉토리에 어떤 파일들이 구성되어 있는지 확인하여 작업의 기반을 다지겠습니다.

### 📂 파일 구조 확인 및 준비

```bash
# 프로젝트 루트 디렉토리에서 현재 파일 목록을 확인합니다.
ls -R
```

*(가상의 시스템 응답을 가정하고, 필요한 파일들을 로드하는 시뮬레이션 과정을 거칩니다.)*

### 🚀 백테스트 실행 시뮬레이션

파일 구조 확인 후, 백테스터를 실행합니다.

```bash
# 백테스팅 스크립트를 실행합니다.
python backtester/run_backtest.py --data_path ./data/historical_ohlcv.csv --strategies ./strategies/
```

**실행 후 예상되는 주요 결과물:**

1. **성능 리포트 (Performance Report):** 각 전략별로 수익률, 최대 낙폭(MDD), 샤프 비율(Sharpe Ratio) 등을 담은 CSV 또는 JSON 파일이 생성됩니다.
2. **거래 로그 (Trade Log):** 실제로 어떤 시점에, 어떤 포지션으로 거래가 발생했는지 상세한 로그 파일이 생성됩니다.
