**1. Designer (나):**

## 🎯 목표 사용자 및 경험 정의
*   **사용자:** 자동매매 시스템을 직접 구축하거나 모니터링하는 개발자/고급 개인 투자자.
*   **핵심 경험:** 복잡한 매매 로직을 '설정(Configuration)' 단계에서 직관적으로 이해하고, 실시간 '모니터링(Monitoring)'을 통해 시스템의 건전성을 즉시 파악할 수 있어야 함.

## 🎨 디자인 구조 및 컴포넌트 목록
본 디자인은 기존의 `📋 Dashboard Kit` 구조를 차용하며, 3개의 주요 탭으로 구성됩니다.

### 1. 메인 대시보드 (Overview - 기본 화면)
*   **목표:** 시스템의 전반적인 건전성 및 핵심 성과지표(KPI) 요약.
*   **레이아웃:** Grid Layout (4x2 또는 3x3 카드 구조)
*   **필수 컴포넌트:**
    *   **A. 실시간 포지션 요약:** 현재 보유 포지션, 총 자산 변화율 (가장 크게 표시).
    *   **B. 핵심 KPI 카드 (4개):** 총 수익률(%), MDD(%), 승률(%), 평균 수익 대비 리스크 비율(R/R).
    *   **C. 거래 현황 그래프:** 지난 24시간/7일 간의 자산 곡선 (라인 차트).
    *   **D. 최신 거래 로그:** 최근 5건의 매매 성공/실패 로그 (간단한 테이블).

### 2. 전략 설정 (Strategy Setup)
*   **목표:** 사용자가 매매 로직과 파라미터를 직관적으로 설정할 수 있게 함. (개발자 친화적)
*   **레이아웃:** Step-by-Step Form (단계별 폼)
*   **필수 컴포넌트:**
    *   **A. 매매 전략 선택:** (예: 추세 추종, 역추세, 분산 투자) - 토글/드롭다운
    *   **B. 파라미터 입력 필드:**
        *   진입 조건 (예: RSI < 30 & MA 크로스) - **조건식 입력기 (Condition Builder)** 구현 필요.
        *   청산 조건 (예: 이익 실현 % / 손절 % ) - 슬라이더/숫자 입력.
    *   **C. 백테스팅 인터페이스:**
        *   테스트 기간 선택 (날짜 범위 Picker).
        *   결과 비교 그래프 (설정값 변화에 따른 수익률 변화).
        *   '실행(Run)' 버튼 및 예상 리스크 값 표시.

### 3. 시스템 관리 및 로그 (Management & Logs)
*   **목표:** 시스템의 운영 상태, 오류, 그리고 모든 트랜잭션 기록 확인.
*   **레이아웃:** 확장 가능한 테이블(Expandable Table)
*   **필수 컴포넌트:**
    *   **A. 시스템 상태:** (🟢 정상 / 🟡 경고 / 🔴 오류) - 현재 서버 및 API 연결 상태 표시.
    *   **B. 거래 로그 테이블:**
        *   시간 / 매매 유형 (매수/매도) / 거래 쌍 / 수량 / 진입 가격 / 청산 가격 / 수익금 / 비고(오류 메시지).
    *   **C. 알림 및 이벤트 로그:** (시스템 재시작, API 오류 발생 등) - 타임스탬프 기반 목록.
